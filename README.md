# 사초: 춘추필법 (史草: 春秋筆法)
> **Sacho: The Silent Brush** — 조선시대 사관 시점의 무한 정치 시뮬레이션 웹게임 프로토타입

---

## 1. 게임 개요

**"붓 끝에 역사가 있고, 침묵 속에 진실이 있다."**

당신은 조선 궁중의 사관(史官)입니다.  
사관은 칼을 쥐지 않았으나, 훗날 실록의 바탕이 될 **'사초(史草)'**를 통해 권력자들의 운명과 역사의 평가를 결정합니다.

본 프로토타입은 다음 핵심 가설을 검증하기 위해 제작되었습니다:
> **“NPC들이 플레이어 없이도 서로 관계하고 행동하면서 정치적 사건을 만들어내고, 플레이어가 그중 일부만 관찰한 뒤 기록 여부를 결정하는 과정이 재미있는가?”**

---

## 2. 핵심 설계 원칙: 4계층 정보 분리

이 게임에는 플레이어에게 곧바로 주어지는 객관적 "정답"이 없습니다:

1. **객관적 진실 (World Fact)**: 실제로 일어난 사실 (뇌물을 받았는가? 결백한가? 밀담이 있었는가?) — *오직 디버그 모드에서만 열람 가능*
2. **NPC의 주관적 믿음 (Agent Belief)**: 각 인물이 알고 있거나 호감도/편견에 의해 믿고 있는 지식
3. **사관의 관찰 정보 (Player Observation)**: 플레이어가 선택한 장소에서 들은 목격담, 전언, 소문 (정보 비대칭)
4. **사초 집필 기록 (Historiographical Record)**: 플레이어가 주관적으로 단정하거나 신중하게 남긴 영구 역사 기록

---

## 3. 주요 시스템

### 1) 12인의 조정 인물
- **주상 전하 (국왕)**: 조정의 세력 균형을 감시하며 권위를 지키는 군주
- **영의정 / 좌의정 / 우의정**: 안정과 개혁, 차기 영의정 승진을 두고 대립하는 의정부 삼정승
- **이조판서 / 병조판서**: 문·무관 인사권과 군사권을 쥔 핵심 권신
- **사헌부 대사헌 / 사간원 대사간**: 백관 감찰과 성역 없는 탄핵을 주도하는 양사(兩司)의 수장
- **홍문관 수찬 / 승정원 도승지**: 경연과 어명 출납, 여론을 주도하는 궐내 핵심 관원
- **대전 상선 (내관) / 승정원 서리**: 궐내 비밀 밀담과 뜬소문을 유통하는 은밀한 정보원

### 2) 비대칭 관계 & 인과적 사건 엔진 (Emergent Politics)
- A가 B를 보는 관계와 B가 A를 보는 관계가 독립적인 비대칭 시스템 (-100 ~ +100)
- 단순 무작위 이벤트가 아닌, **[야심 + 원한 + 명분 + 비대칭 관계 + 과거 기억]**에 의해 필연적으로 일어나는 **원인 $\rightarrow$ 행동 $\rightarrow$ 결과** 구조:
  1. 인사 추천 (Appointment Recommendation)
  2. 승진 경쟁 (Promotion Rivalry)
  3. 탄핵 상소 (Impeachment)
  4. 왕의 공개 질책 (Royal Reprimand)
  5. 대신 간 공개 논쟁 (Public Debate)
  6. 비밀 회동 (Secret Meeting)
  7. 뇌물 의혹 (Bribery Allegation)
  8. 소문 발생 (Rumor Inception)
  9. 정치적 지원 (Political Alliance)
  10. 특정 인물 모함 (Slander)

### 3) 5대 관찰 장소
- **편전 (便殿)**: 어전 회의, 공개 논쟁, 어명, 탄핵 상소가 울려 퍼지는 장소
- **승정원 (承政院)**: 공문서와 어명이 출납되며 소식이 집약되는 정보의 관문
- **사헌부 (司憲府)**: 비리 첩보와 내사, 탄핵안이 기안되는 풍헌의 관청
- **사간원 (司諫院)**: 간관들이 모여 권신의 전횡을 성토하는 언론의 중심
- **궐내 회랑 (闕內 回廊)**: 비밀 밀담, 뇌물 청탁, 뜬소문이 오가는 은밀한 공간

### 4) 3단계 사초 집필 시스템
- 플레이어는 하루에 한 장소만 선택하여 정보를 관찰합니다.
- 각 정보마다 기록 여부와 표현 강도를 선택합니다:
  - **묵살**: 역사에서 제외
  - **신중한 표현**: *"~라는 말이 있었다"* (전언 형식)
  - **비교적 강한 표현**: *"~한 정황이 포착되었다"* (의혹 강조)
  - **단정적 표현**: *"~가 명백한 간신이다"* (확정적 규정)
- 플레이어 역시 거짓 소문에 속아 왜곡된 역사를 기록할 수 있습니다.

### 5) 시뮬레이션 디버그 콘솔 & PRNG Seed
- **동일 Seed 입력 시 100% 동일한 사건 연쇄 재현** (Mulberry32 PRNG)
- 디버그 패널을 열어 WorldFact 진실, NPC 내부 수치, 12x12 관계 매트릭스, 사건 인과 추적, 실시간 콘솔 로그를 즉시 확인 가능.

## 4. 로컬 실행 및 빌드 방법

### 요구 사항
- Node.js 20+
- npm 10+

### 개발 서버 실행
```bash
# 의존성 설치
npm install

# 로컬 개발 서버 구동
npm run dev
```
브라우저에서 `http://127.0.0.1:5173` 접속.

### 자동화 테스트 실행
```bash
npm test
```

### 프로덕션 빌드
```bash
npm run build
```
